# Upline Rakshak

Upline Rakshak is a Progressive Web Application (PWA) that helps users interact with the system using both text and voice input. The platform focuses on accessibility, reliability, and smooth user experience across desktop and mobile devices.

## Live Demo
https://upline-rakshak.vercel.app/#/dashboard

## Features

- Voice input support
- Automatic retry when microphone fails
- Clear fallback message if voice input is unavailable
- Progressive Web App (PWA) support
- Mobile-friendly responsive design
- Dashboard interface for user interaction
- Backend API integration
- Deployment configuration for cloud hosting
